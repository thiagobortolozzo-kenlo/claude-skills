# Radar de skills: candidatas do kursku/skills

O [github.com/kursku/skills](https://github.com/kursku/skills) tem 1.853 skills. **78 já entraram** neste repo depois de auditadas. As outras ficaram de fora por um destes motivos: são genéricas demais, repetem o que já temos, são de nicho técnico que o time não usa, ou são arriscadas.

Abaixo estão as candidatas que **podem valer a pena** se alguém do time precisar. Elas **não foram auditadas linha a linha** ainda.

## Como pedir uma

1. Abra uma issue **"Sugerir skill"** com o nome e o motivo.
2. Quem for importar segue "Importar uma skill de fora" no [CONTRIBUTING](../CONTRIBUTING.md): lê tudo, coloca na área certa, escreve o README e registra no NOTICE.

## Não trazer

| Skill | Motivo |
|---|---|
| `loki-mode` | Roda o Claude sem pedir permissão, em loop autônomo |
| `codex-ask`, `gemini-ask`, `kimi-ask` | Enviam código e contexto para outras IAs |
| `evolution` | Instala hooks baixando e executando um script da internet |
| `apify-*`, `firecrawl-scraper`, `x-twitter-scraper` | Scraping e envio de dados para serviços de terceiros |
| `skill-installer`, `skillshare`, `oss-hunter` | Baixam e instalam mais código sozinhos |
| `*-privilege-escalation`, `metasploit-framework`, `red-team-*`, `*-penetration-testing` | Conteúdo ofensivo, só faz sentido em pentest autorizado |
| `*-health-analyzer` | Fora do escopo e com dados sensíveis |
| Duplicatas de plugins já instalados (`docx-official`, `xlsx-official`, `pptx-official`, `pdf-official`, `systematic-debugging`, `writing-plans` etc.) | Já vêm nos plugins oficiais |
