# Novidade Kenlo · skill

## Para que serve

Transformar documentação de novidades Kenlo em seis conteúdos coerentes: artigo SEO, e-mail, mensagem interna, on-site, carrossel e Reels/Short de até 50 segundos.

## Quando usar

Após receber documentação e briefing de uma atualização de produto. Exemplo: `/kenlo-novidade crie o pacote com base no briefing anexado`.

## Como funciona

Instalar a área com `./install.sh 02-copy-conteudo` ou `.\\install.ps1 -Area 02-copy-conteudo`, na raiz do repositório. O instalador copia esta pasta para `~/.claude/skills/kenlo-novidade/`. Abrir uma nova sessão e chamar `/kenlo-novidade`.

Ler as fontes, separar novidade de recurso existente e preparar os formatos solicitados. E-mail aponta para a página do produto; on-site aponta para a página da novidade.

## O que entrega

H1, descrição curta, title SEO, meta description, slug e artigo; três assuntos, preheader, e-mail e CTA; chat interno; campos on-site; cards e legenda; cenas, animação, off e legenda de vídeo.

## Arquivos da skill

`SKILL.md` contém o fluxo completo adaptado do agente personalizado Novidade Kenlo. Não depende de scripts ou arquivos de apoio ocultos. Knowledge e anexos do ChatGPT precisam ser fornecidos pelo usuário quando necessários.

## Cuidados

Uso interno Kenlo. Gerar rascunhos e orientações, sem publicar, enviar ou agendar. Usar placeholders para URLs ausentes. Não incluir dados pessoais de clientes ou credenciais nas saídas. O tempo do off é estimado por texto; validar a leitura antes de produzir o vídeo.
