# Imagem e foto

Geração e edição de imagem com IA, peças estáticas, arte generativa e GIFs.

**8 skills**

.

Clique no nome para ver a explicação completa de como a skill funciona.

| Skill | Como chamar | Para que serve | Requer |
|---|---|---|---|
| [**ai-studio-image**](ai-studio-image/README.md) | `/ai-studio-image` | Fotos realistas via Gemini (Google AI Studio). Precisa de GEMINI_API_KEY. | Python, chave Gemini |
| [**algorithmic-art**](algorithmic-art/README.md) | `/algorithmic-art` | Arte generativa em p5.js com parâmetros interativos. | — |
| [**canvas-design**](canvas-design/README.md) | `/canvas-design` | Pôsteres e peças visuais em PNG e PDF a partir de uma filosofia de design. | — |
| [**image**](image/README.md) | `/image` | Criação e otimização de imagens de marketing (hero, social, banners, WebP). | — |
| [**image-studio**](image-studio/README.md) | `/image-studio` | Roteia o pedido de imagem para ai-studio-image (foto) ou stability-ai (arte/edição). | — |
| [**personal-brand-photography**](personal-brand-photography/README.md) | `/personal-brand-photography` | Direção de fotos para marca pessoal (PT-BR). | — |
| [**slack-gif-creator**](slack-gif-creator/README.md) | `/slack-gif-creator` | GIFs animados otimizados para Slack e Chat (Python/Pillow, local). | Python |
| [**stability-ai**](stability-ai/README.md) | `/stability-ai` | Geração e edição de imagem via Stability AI (inpainting, upscale, remover fundo). Precisa de STABILITY_API_KEY. | Python, chave Stability |
