# Agentes · Redes sociais

Subagentes que o Claude Code chama para tarefas maiores. O instalador copia cada `AGENT.md` para `~/.claude/agents/<nome>.md`.

| Agente | Para que serve |
|---|---|
| [**kenlo-social-listener**](kenlo-social-listener/README.md) | [Kenlo] Rotina diária: lê as redes da Kenlo, separa quem precisa de suporte, valida no Kenlo Brain e rascunha o encaminhamento. |
| [**kenlo-social-responder**](kenlo-social-responder/README.md) | [Kenlo] Rascunha respostas públicas a elogios, críticas e parcerias na voz da Kenlo; só publica com aprovação. |
